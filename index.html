Jogo da Cobrinha
Snake Game

Um jogo clássico da cobrinha desenvolvido com HTML, CSS e JavaScript puro, apresentando uma estética retrô inspirada nos tradicionais jogos de arcade. O projeto conta com controles pelas teclas W, A, S e D, sistema de fases com aumento progressivo da velocidade a cada 5 pontos conquistados, tela inicial com GIF animado, tela de Game Over com opções para reiniciar a partida ou retornar ao menu principal, HUD com exibição da pontuação, fase atual e instruções de jogo, além de efeitos sonoros para coleta de alimentos, avanço de fase e Game Over.

Prototipagem das telas do Nubank

Projeto que teve como objetivo reunir a prototipagem das telas do Nubank, desenvolvida nativamente no Android Studio. O foco principal foi replicar a experiência do usuário (UX) e a interface (UI) de um dos fluxos mais utilizados do banco digital: a área de transações Pix e transferências bancárias.

API Comercial

API desenvolvida em Node.js com o framework Express, voltada para a gestão de um ecossistema comercial completo através do controle de clientes, produtos, categorias e vendas. O projeto adota uma arquitetura estruturada em middlewares, models e rotas, utilizando o MongoDB (Mongoose) como banco de dados não-relacional. Visando a segurança e a integridade da aplicação, foi implementado um sistema rigoroso de autenticação e criptografia de ponta a ponta com JSON Web Tokens (JWT) e BcryptJS, garantindo que as rotas de gerenciamento sejam acessadas apenas por usuários autenticados.

CRUD em PHP

Aplicação web desenvolvida em PHP com foco no gerenciamento de dados através de um sistema CRUD completo (Inclusão, Consulta, Atualização e Exclusão). A interface foi construída utilizando HTML, CSS, JavaScript e SCSS, garantindo uma estrutura organizada, estilização moderna e interatividade fluida.

iFood Clone

Aplicativo Android desenvolvido nativamente no Android Studio com Kotlin e layouts em XML, focado na reprodução da experiência visual do iFood. O projeto mapeia de forma simples a interface de fluxo de compra de um marketplace de delivery, permitindo a visualização de detalhes do produto, inserção de observações e adição de itens ao carrinho.

Artigo Científico

O artigo científico aborda o impacto do phishing como uma das principais ameaças à segurança digital contemporânea, analisando o problema sob as óticas técnica, educativa e jurídica. O objetivo central do estudo é capacitar a comunidade digital para reconhecer e prevenir esses ataques cibernéticos, mitigando os severos prejuízos que eles causam à sociedade.
